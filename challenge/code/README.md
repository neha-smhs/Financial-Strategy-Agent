# Code entry points

See ../README.md. Run commands from challenge/.

- evidence.py: OCR and local facts
- api_evidence.py: validated optional model extraction
- forecast.py: 90-day cash-flow simulation
- planner.py: plan selection and arithmetic replay
- validate_output.py: serialized output validation
- evaluate.py and compare_revision.py: public development evaluation
